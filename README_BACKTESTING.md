# 📊 Скрипт бэктестинга торговой стратегии BTC (Лонг + Шорт)

## Описание

Скрипт для оценки доходности торговой стратегии BTC на основе индекса страха и жадности (Fear & Greed Index) с использованием лонг и шорт позиций.

## 🎯 Стратегия

### Лонг позиции:
- **Открытие**: Когда индекс страха и жадности = 20 (Extreme Fear)
  - Покупка BTC на весь капитал
- **Закрытие**: Когда индекс страха и жадности = 80 (Extreme Greed)
  - Продажа всего BTC

### Шорт позиции:
- **Открытие**: Когда индекс страха и жадности = 85 (Extreme Greed)
  - Открытие шорта BTC на весь капитал (плечо 1)
- **Закрытие**: Когда индекс страха и жадности = 25 (Extreme Fear)
  - Закрытие шорта (выкуп BTC)

### Параметры:
- **Стартовый капитал**: $1,000
- **Период тестирования**: 01.01.2020 - 01.12.2025
- **Актив**: BTC (BTCUSDT)
- **Плечо шорта**: 1x

**Важно**: Условия срабатывают при **точном равенстве** индекса (= 20, = 80, = 85, = 25), а не диапазоне.

## 📊 Что делает скрипт

1. **Получает данные BTC с Binance**:
   - Исторические дневные свечи BTCUSDT
   - Используется публичный API (не требует ключей)

2. **Получает индекс страха и жадности**:
   - Данные с alternative.me API
   - Исторические значения индекса

3. **Выполняет бэктестинг**:
   - Симулирует торговлю BTC с лонг и шорт позициями
   - Отслеживает все сделки
   - Рассчитывает P&L для каждой позиции
   - Рассчитывает стоимость портфеля на каждую дату

4. **Рассчитывает статистику**:
   - Циклы лонг и шорт сделок
   - Win Rate (процент прибыльных сделок)
   - Максимальная просадка (Max Drawdown)
   - Финальная доходность
   - Сравнение с HODL BTC стратегией

## 📈 Выходные данные

Скрипт создает следующие файлы:

### 1. `backtesting_results_btc.json`
Содержит:

- Детальную статистику
- Список всех сделок с датами, ценами, P&L

### 2. `portfolio_history_btc.csv`
Содержит ежедневную историю портфеля:
- Дата
- Стоимость портфеля
- Цена BTC
- Индекс страха и жадности
- Тип позиции (LONG/SHORT/NONE)

## 🔧 Настройка параметров

Вы можете изменить параметры стратегии в классе `BTCTradingStrategy`:

```python
class BTCTradingStrategy:
    def __init__(self, initial_capital: float = 1000.0):
        self.initial_capital = initial_capital
        # Пороги для лонг позиций
        self.long_buy_threshold = 20   # Покупка BTC
        self.long_sell_threshold = 80  # Продажа BTC
        # Пороги для шорт позиций
        self.short_open_threshold = 85  # Открытие шорта
        self.short_close_threshold = 25 # Закрытие шорта
        self.leverage = 1  # Плечо для шорта
```

Параметры периода в функции `main()`:

## 💡 Как работает шорт с плечом 1

### Пример открытия шорта:
- Капитал: $1,000
- Цена BTC: $50,000
- Занимаем: 0.02 BTC
- Продаем за: $1,000

### Если цена упала до $40,000 (прибыль):
- Выкупаем 0.02 BTC за: $800
- Прибыль: $1,000 - $800 = $200
- Итого капитал: $1,200

### Если цена выросла до $60,000 (убыток):
- Выкупаем 0.02 BTC за: $1,200
- Убыток: $1,000 - $1,200 = -$200
- Итого капитал: $800

## ⚠️ Важные замечания

1. **Не финансовый совет**: Результаты бэктестинга не гарантируют будущей доходности
2. **Комиссии не учитываются**: Скрипт не учитывает торговые комиссии
3. **Комиссия за финансирование**: Не учитывается funding rate для шорт позиций
4. **Проскальзывание**: Не учитывается проскальзывание цены при исполнении ордеров
5. **Ликвидность**: Предполагается, что можно открыть/закрыть позицию по текущей цене
6. **Налоги**: Налоги на прибыль не учитываются
7. **Точные сигналы**: Стратегия срабатывает только при индексе ТОЧНО = 20/80/85/25 (не диапазон)
8. **Риск ликвидации**: При шорте с плечом есть риск ликвидации при сильном росте цены (в данной стратегии плечо = 1, минимальный риск)
9. **Одновременные позиции**: Лонг и шорт не открываются одновременно
