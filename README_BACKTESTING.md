# 📊 Скрипт бэктестинга торговой стратегии BTC (Лонг)

## Описание

Скрипт для оценки доходности торговой стратегии BTC на основе индекса страха и жадности (Fear & Greed Index) с использованием лонг позиций.

## 🎯 Стратегия

### Лонг позиции:
- **Открытие**: Когда индекс страха и жадности < 20 (Extreme Fear)
  - Покупка BTC на весь капитал
- **Закрытие**: Когда индекс страха и жадности > 80 (Extreme Greed)
  - Продажа всего BTC

### Параметры:
- **Стартовый капитал**: $1,000
- **Период тестирования**: 01.01.2020 - 01.12.2025
- **Актив**: BTC (BTCUSDT)

**Важно**: Условия срабатывают при пересечении порогов (< 20, > 80).

## 📊 Что делает скрипт

1. **Получает данные BTC с Binance**:
   - Исторические дневные свечи BTCUSDT
   - Используется публичный API (не требует ключей)

2. **Получает индекс страха и жадности**:
   - Данные с alternative.me API
   - Исторические значения индекса

3. **Выполняет бэктестинг**:
   - Симулирует торговлю BTC с лонг позициями
   - Отслеживает все сделки
   - Рассчитывает стоимость портфеля на каждую дату

4. **Рассчитывает статистику**:
   - Циклы лонг сделок
   - Win Rate (процент прибыльных сделок)
   - Максимальная просадка (Max Drawdown)
   - Финальная доходность
   - Сравнение с HODL BTC стратегией

## 📈 Выходные данные

Скрипт создает следующие файлы:

### 1. `backtesting_results_btc.json`
Содержит:
- Параметры стратегии (пороги для лонга)
- Детальную статистику
- Список всех сделок с датами и ценами

### 2. `portfolio_history_btc.csv`
Содержит ежедневную историю портфеля:
- Дата
- Стоимость портфеля
- Цена BTC
- Индекс страха и жадности
- Тип позиции (LONG/NONE)

## 🔧 Настройка параметров

Вы можете изменить параметры стратегии в классе `BTCTradingStrategy`:

```python
class BTCTradingStrategy:
    def __init__(self, initial_capital: float = 1000.0):
        self.initial_capital = initial_capital
        # Пороги для лонг позиций
        self.long_buy_threshold = 20   # Покупка BTC
        self.long_sell_threshold = 80  # Продажа BTC
```

Параметры периода в функции `main()`:
```python
start_date = "2020-01-01"    # Начало периода
end_date = "2025-12-01"      # Конец периода
initial_capital = 1000.0     # Стартовый капитал
```

## 🌐 Используемые API

### Binance API
- **URL**: https://api.binance.com/api/v3
- **Endpoint**: /klines
- **Назначение**: Получение исторических цен BTC
- **Документация**: https://binance-docs.github.io/apidocs/

### Fear & Greed Index API
- **URL**: https://api.alternative.me/fng/
- **Назначение**: Получение исторических значений индекса
- **Документация**: https://alternative.me/crypto/fear-and-greed-index/

## ⚠️ Важные замечания

1. **Не финансовый совет**: Результаты бэктестинга не гарантируют будущей доходности
2. **Комиссии не учитываются**: Скрипт не учитывает торговые комиссии
3. **Проскальзывание**: Не учитывается проскальзывание цены при исполнении ордеров
4. **Ликвидность**: Предполагается, что можно открыть/закрыть позицию по текущей цене
5. **Налоги**: Налоги на прибыль не учитываются
6. **Пороговые сигналы**: Стратегия срабатывает при пересечении порогов < 20, > 80
