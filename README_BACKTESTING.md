# 📊 Скрипт бэктестинга торговой стратегии BTC (Двухэтапная с EMA)

## Описание

Скрипт для оценки доходности торговой стратегии BTC на основе **двухэтапной системы сигналов**:
1. Индекс страха и жадности (Fear & Greed Index)
2. Пересечения экспоненциальных скользящих средних (EMA)

## 🎯 Стратегия (Двухэтапная)

### 📈 Покупка BTC (2 этапа):

**Этап 1 - Активация сигнала:**
- Индекс страха и жадности < 20 (Extreme Fear)
- После активации бот **ждет** выполнения второго условия
- ⚠️ **Важно**: Даже если индекс поднимется выше 20, сигнал остается активным!

**Этап 2 - Исполнение:**
- EMA 20 (4-часовой) пересекает EMA 50 (4-часовой) **снизу вверх** (Golden Cross)
- → **ПОКУПКА BTC** на весь капитал

### 📉 Продажа BTC (2 этапа):

**Этап 1 - Активация сигнала:**
- Индекс страха и жадности > 80 (Extreme Greed)
- После активации бот **ждет** выполнения второго условия

**Этап 2 - Исполнение:**
- EMA 20 (4-часовой) пересекает EMA 50 (4-часовой) **сверху вниз** (Death Cross)
- → **ПРОДАЖА BTC** (весь объем)

### Параметры:
- **Стартовый капитал**: $1,000
- **Период тестирования**: 01.01.2020 - 01.12.2025
- **Актив**: BTC (BTCUSDT)
- **Таймфрейм EMA**: 4 часа
- **EMA периоды**: EMA 20 и EMA 50

**Ключевая особенность**: Сигналы НЕ отменяются, если индекс страха возвращается обратно. Бот продолжает ждать пересечения EMA.

## 📊 Что делает скрипт

1. **Получает 4-часовые данные BTC с Binance**:
   - Исторические 4-часовые свечи BTCUSDT
   - Используется публичный API (не требует ключей)
   - Нужны для расчета EMA

2. **Получает индекс страха и жадности**:
   - Данные с alternative.me API
   - Исторические дневные значения индекса

3. **Рассчитывает технические индикаторы**:
   - EMA 20 на 4-часовых свечах
   - EMA 50 на 4-часовых свечах
   - Детектирует пересечения (Golden Cross / Death Cross)

4. **Выполняет бэктестинг**:
   - Симулирует двухэтапную торговлю BTC
   - Отслеживает активацию сигналов и их исполнение
   - Рассчитывает стоимость портфеля на каждую 4-часовую свечу

5. **Рассчитывает статистику**:
   - Циклы лонг сделок
   - Win Rate (процент прибыльных сделок)
   - Максимальная просадка (Max Drawdown)
   - Финальная доходность
   - Сравнение с HODL BTC стратегией

## 📈 Выходные данные

Скрипт создает следующие файлы:

### 1. `backtesting_results_btc.json`
Содержит:
- Параметры стратегии (пороги индекса, периоды EMA, таймфрейм)
- Детальную статистику
- Список всех сделок с датами, ценами, значениями EMA

### 2. `portfolio_history_btc.csv`
Содержит 4-часовую историю портфеля:
- Дата и время (4-часовые интервалы)
- Стоимость портфеля
- Цена BTC
- Индекс страха и жадности
- Значения EMA 20 и EMA 50
- Тип позиции (LONG/WAITING_BUY/WAITING_SELL/NONE)

## 📚 Объяснение терминов

### EMA (Экспоненциальная скользящая средняя)
- **EMA 20**: Быстрая скользящая средняя, реагирует на изменения цены быстрее
- **EMA 50**: Медленная скользящая средняя, более сглаженная

### Пересечения EMA
- **Golden Cross** (Золотой крест): EMA 20 пересекает EMA 50 снизу вверх
  - Бычий сигнал, указывает на начало восходящего тренда
  - В нашей стратегии: сигнал на ПОКУПКУ

- **Death Cross** (Крест смерти): EMA 20 пересекает EMA 50 сверху вниз
  - Медвежий сигнал, указывает на начало нисходящего тренда
  - В нашей стратегии: сигнал на ПРОДАЖУ

## 🌐 Используемые API

### Fear & Greed Index API
- **URL**: https://api.alternative.me/fng/
- **Назначение**: Получение исторических значений индекса
- **Документация**: https://alternative.me/crypto/fear-and-greed-index/

## ⚠️ Важные замечания

1. **Не финансовый совет**: Результаты бэктестинга не гарантируют будущей доходности
2. **Комиссии не учитываются**: Скрипт не учитывает торговые комиссии
3. **Проскальзывание**: Не учитывается проскальзывание цены при исполнении ордеров
4. **Ликвидность**: Предполагается, что можно открыть/закрыть позицию по текущей цене
5. **Налоги**: Налоги на прибыль не учитываются
6. **Двухэтапные сигналы**: Стратегия использует комбинацию индекса страха (< 20, > 80) и пересечений EMA
7. **EMA задержка**: EMA требует накопления данных (первые 50 свечей используются для расчета)
8. **Сигналы не отменяются**: Если индекс опустился < 20, сигнал остается активным даже если индекс вернется > 20
