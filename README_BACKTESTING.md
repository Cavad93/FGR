# 📊 Скрипт бэктестинга торговой стратегии TOP-20 криптовалют

## Описание

Скрипт для оценки доходности торговой стратегии на основе индекса страха и жадности (Fear & Greed Index) с использованием портфеля из топ-20 криптовалют по капитализации.

## 🎯 Стратегия

- **Покупка**: Когда индекс страха и жадности = 20 (Extreme Fear)
  - **Динамически** определяются топ-20 монет по капитализации **на момент сигнала покупки**
  - Исключаются все стейблкоины
  - По 5% капитала на каждую монету (20 × 5% = 100%)
- **Продажа**: Когда индекс страха и жадности = 80 (Extreme Greed)
  - Продаются все купленные монеты
- **Стартовый капитал**: $1,000
- **Период тестирования**: 01.01.2020 - 01.12.2025

**Важно**: Топ-20 монет определяется заново на каждую дату покупки, а не используется один и тот же набор монет.

## 📊 Что делает скрипт

1. **Получает топ-50 монет с CoinGecko**:
   - Текущие топ-50 монет по капитализации
   - Получает circulating supply для каждой монеты
   - Автоматически исключает стейблкоины (USDT, USDC, DAI и др.)
   - Используется публичный API (не требует ключей)

2. **Получает данные с Binance**:
   - Исторические дневные свечи для всех 50 монет
   - Формат: SYMBOL + USDT (например, BTCUSDT, ETHUSDT)
   - Используется публичный API (не требует ключей)

3. **Получает индекс страха и жадности**:
   - Данные с alternative.me API
   - Исторические значения индекса

4. **Выполняет бэктестинг с динамическим выбором топ-20**:
   - На каждую дату, когда индекс = 20:
     - Рассчитывает капитализацию всех 50 монет (цена × circulating supply)
     - Выбирает топ-20 по капитализации на эту дату
     - Покупает эти топ-20 монет
   - Симулирует торговлю портфелем
   - Отслеживает все сделки для каждой монеты
   - Рассчитывает стоимость портфеля на каждую дату

5. **Рассчитывает статистику**:
   - Циклы торговли (покупка-продажа)
   - Win Rate (процент прибыльных циклов)
   - Максимальная просадка (Max Drawdown)
   - Финальная доходность
   - Сравнение с HODL BTC стратегией

## 🌐 Используемые API

### CoinGecko API
- **URL**: https://api.coingecko.com/api/v3
- **Endpoint**: /coins/markets
- **Назначение**: Получение топ-20 монет по капитализации
- **Документация**: https://www.coingecko.com/en/api/documentation

### Binance API
- **URL**: https://api.binance.com/api/v3
- **Endpoint**: /klines
- **Назначение**: Получение исторических цен для всех монет
- **Документация**: https://binance-docs.github.io/apidocs/

### Fear & Greed Index API
- **URL**: https://api.alternative.me/fng/
- **Назначение**: Получение исторических значений индекса
- **Документация**: https://alternative.me/crypto/fear-and-greed-index/

## ⚠️ Важные замечания

1. **Не финансовый совет**: Результаты бэктестинга не гарантируют будущей доходности
2. **Комиссии не учитываются**: Скрипт не учитывает торговые комиссии (обычно 0.1% на Binance)
3. **Проскальзывание**: Не учитывается проскальзывание цены при исполнении ордеров
4. **Ликвидность**: Предполагается, что можно купить/продать любой объем по текущей цене
5. **Налоги**: Налоги на прибыль не учитываются
6. **Динамический топ-20**: На каждую дату покупки определяется топ-20 по капитализации (цена × circulating supply). Circulating supply берется текущий из CoinGecko (не исторический, т.к. это платная функция API)
7. **Точные сигналы**: Стратегия срабатывает только при индексе ТОЧНО = 20 или = 80 (не диапазон)
8. **Стейблкоины**: Автоматически исключаются все известные стейблкоины из портфеля
9. **Пул монет**: Для выбора топ-20 используется пул из топ-50 текущих монет по CoinGecko
