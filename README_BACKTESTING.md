# 📊 Скрипт бэктестинга торговой стратегии BTC

## Описание

Скрипт для оценки доходности торговой стратегии на основе индекса страха и жадности (Fear & Greed Index) с использованием исторических данных BTCUSDT.

## 🎯 Стратегия

- **Покупка**: Когда индекс страха и жадности < 20 (Extreme Fear)
- **Продажа**: Когда индекс страха и жадности > 80 (Extreme Greed)
- **Стартовый капитал**: $1,000
- **Период тестирования**: 01.01.2020 - 01.12.2025

## 📋 Требования

- Python 3.7+
- Доступ к интернету
- Установленные библиотеки:
  - pandas
  - requests

```bash
pip install pandas requests
```

### 2. Запуск скрипта

```bash
python3 backtesting_strategy.py
```

## 📊 Что делает скрипт

1. **Получает данные с Binance**:
   - Исторические дневные свечи BTCUSDT
   - Используется публичный API (не требует ключей)

2. **Получает индекс страха и жадности**:
   - Данные с alternative.me API
   - Исторические значения индекса

3. **Выполняет бэктестинг**:
   - Симулирует торговлю по стратегии
   - Отслеживает все сделки
   - Рассчитывает портфель

4. **Рассчитывает статистику**:
   - Общее количество сделок
   - Win Rate (процент прибыльных сделок)
   - Максимальная просадка (Max Drawdown)
   - Финальная доходность
   - Сравнение с HODL стратегией

## 📈 Выходные данные

Скрипт создает следующие файлы:

### 1. `backtesting_results.json`
Содержит:
- Параметры стратегии
- Детальную статистику
- Список всех сделок с датами, ценами и индексами

### 2. `portfolio_history.csv`
Содержит ежедневную историю портфеля:
- Дата
- Стоимость портфеля
- Цена BTC
- Индекс страха и жадности
- Наличные средства
- Количество BTC

## 🔧 Настройка параметров

Вы можете изменить параметры стратегии в функции `main()`:

```python
# Параметры
symbol = "BTCUSDT"           # Торговая пара
interval = "1d"              # Интервал свечей
start_date = "2020-01-01"    # Начало периода
end_date = "2025-12-01"      # Конец периода
initial_capital = 1000.0     # Стартовый капитал
buy_threshold = 20           # Порог покупки (индекс < 20)
sell_threshold = 80          # Порог продажи (индекс > 80)
```

## ⚠️ Важные замечания

1. **Не финансовый совет**: Результаты бэктестинга не гарантируют будущей доходности
2. **Комиссии не учитываются**: Скрипт не учитывает торговые комиссии
3. **Проскальзывание**: Не учитывается проскальзывание цены при исполнении ордеров
4. **Ликвидность**: Предполагается, что можно купить/продать любой объем по текущей цене
5. **Налоги**: Налоги на прибыль не учитываются
